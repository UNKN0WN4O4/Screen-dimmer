# 🌑 Screen Dimmer

A lightweight, user-friendly desktop application designed to adjust your screen brightness quickly. Features a visual slider interface and global keyboard shortcuts for seamless control.


## ✨ Features

* **Global Hotkeys:** Adjust brightness instantly from anywhere without opening the app window.
* **Visual Interface:** precise control using a GUI slider.
* **Portable:** No complex installation required.
* **System Tray Support:** Runs quietly in the background.

---

## 🎮 Controls

You can control the brightness using the application slider or the following keyboard shortcuts:

| Action | Shortcut |
| :--- | :--- |
| **Decrease Brightness** | <kbd>Ctrl</kbd> + <kbd>Q</kbd> |
| **Increase Brightness** | <kbd>Ctrl</kbd> + <kbd>W</kbd> |

---

## 📥 Installation & Usage

This application is portable. Follow these steps to get started:

1.  Navigate to the **[Releases](../../releases)** section of this repository.
2.  Download the file named `main.7z` from the latest release.
3.  **Extract** the contents of `main.7z` to a folder of your choice (you may need 7-Zip or WinRAR).
4.  Open the extracted folder and double-click **`run.bat`** to start the application.

> **Note:** If Windows SmartScreen prevents the application from running, click "More Info" and then "Run Anyway."
